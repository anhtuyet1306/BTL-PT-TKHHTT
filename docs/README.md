# Hồ sơ phần Vị trí và Kết quả tuyển dụng

Đây là phần tài liệu của sinh viên phụ trách:

- Quản lý vị trí tuyển dụng.
- Admin xem, thêm, sửa, xóa vị trí tuyển dụng.
- Ứng viên xem danh sách và chi tiết vị trí.
- Thiết kế bảng `ViTriTuyenDung`.
- Thiết kế bảng `KetQuaTuyenDung`.

## Danh mục tệp

1. `PHAN_TICH_THIET_KE_VI_TRI_KET_QUA.md`: bản thuyết minh đầy đủ để học và trình bày.
2. `../diagrams/use-case-vi-tri-ket-qua.puml`: sơ đồ Use Case bằng PlantUML.
3. `../diagrams/erd-vi-tri-ket-qua.puml`: sơ đồ ERD bằng PlantUML.
4. `../database/access/README.md`: hướng dẫn dùng bộ CSDL Microsoft Access.
5. `../database/access/01_tao_bang_access.sql`: lệnh tạo bảng và quan hệ.
6. `../database/access/02_du_lieu_mau_access.sql`: dữ liệu minh họa.
7. `../database/access/03_truy_van_mau_access.sql`: truy vấn phục vụ giao diện và báo cáo.
8. `../database/access/TuyenDung_ViTri_KetQua.accdb`: tệp Access mẫu đã tạo sẵn.

> Đây là bài Phân tích và Thiết kế hệ thống thông tin. Các trang PHP trong repository chỉ là prototype giao diện, không phải trọng tâm triển khai.
